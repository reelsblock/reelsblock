ReelsBlock

Use Instagram for messages and friends without Reels, Explore or the home feed. Stories stay. Includes a Study Mode (messages only). Free.

Install
  1. Unzip the downloaded file.
  2. Chrome/Edge (computer): open chrome://extensions, turn on Developer mode, click Load unpacked, pick the folder.
  3. Firefox (computer or Android): open about:debugging → This Firefox → Load Temporary Add-on → pick manifest.json.
  4. Safari (Mac): Safari extensions need a one-time conversion in Xcode (free from the App Store): run xcrun safari-web-extension-converter /path/to/reelsblock in Terminal, build the app, then enable it in Safari → Settings → Extensions. Firefox or Chrome is much easier.
  5. Log in at instagram.com and allow notifications. On Android, add the site to your home screen, then you can delete the Instagram app.

Chrome on Android doesn't support extensions; use Firefox. Not affiliated with Instagram or Meta.
