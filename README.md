Install
Unzip the downloaded file.
Chrome/Edge (computer): open chrome://extensions, turn on Developer mode, click Load unpacked, pick the folder.
Firefox (computer or Android): open about:debugging → This Firefox → Load Temporary Add-on → pick manifest.json.
Safari (Mac): Safari extensions need a one-time conversion in Xcode (free from the App Store): run xcrun safari-web-extension-converter /path/to/reelsblock in Terminal, build the app, then enable it in Safari → Settings → Extensions. Firefox or Chrome is much easier.
Log in at instagram.com and allow notifications. On Android, add the site to your home screen, then you can delete the Instagram app.
Study Mode isn't on the website, it's inside the extension. After you install it, click the puzzle piece icon in your browser's toolbar, then click ReelsBlock. A small popup opens with two switches, Block Reels & Explore and Study Mode. Pin the extension so the icon stays visible.
